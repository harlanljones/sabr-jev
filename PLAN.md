# Sabr-Jev first build

Status: approved by Harlan in interactive interview; implementation beginning.

## Contract
- PRD v0.1.1 + AGENTS.md control. Phoenix LiveView / Elixir; typesafe_api jev-latest; Makefile-driven Python stdlib ETL into local SQLite and derived JSON. No Postgres, Docker, authentication, deployment, commits, or pushes.
- Frozen Lahman inputs with revision, checksum and license lineage. Bulk raw inputs stay ignored. Small real derived demo cards may be committed. Frozen wOBA constants only; missing weights => unavailable.
- Sum counts then compute rates. League context is league-year; traded-player context weighted by PA (batters) or outs (pitchers). Missing optional historical SF/IBB/HBP => zero with warnings; missing core stats or invalid denominators => unavailable, never invented.
- Publish OPS+ (Sabr-Jev) recipe using league OBP/SLG and Teams.BPF; no external parity. FIP constant derived from league ERA identity. Pitcher K-BB% uses BFP.
- Shared artifact: priv/data/cards.json is {schema_version, provenance, cards:[...]}. Each card: id, role (batter|pitcher), player_id, player_name, year, metrics, sample {qualified,minimum,value,unit}, warnings, judgment_state, oracle (separate, nullable). Exact field details are frozen by task 2 and passed to consumers, not guessed.
- judgment_state is allowlisted precomputed numeric context; no identity, next-season outcomes, or oracle fields. Freeze question definitions before live inference; save state/question hashes, model, timestamp, response and source lineage. No fabricated live fixtures. Synthetic unit inputs must be explicitly distinguished from recorded responses.
- Questions: season_read Choice breakout|stable|regression_risk|small_sample|other; confidence_in_signal Score weak/moderate/strong; role profile Choice + other; role Noul only if T+1 exists in historical demo, or in explicitly prospective prediction flow. Code minimums: 200 PA / 50 IP; never deterministic Noul.
- Choice/Score provisional act >=0.8, review >=0.5, else escalate; other => escalate; insufficient sample cannot act. Noul derives max(p,1-p): act >=0.85, otherwise review (no escalate). Noul never escalates a card. Separate thresholds remain provisional.
- Full UI: role + player-season selection, cards, latch, full probabilities in review/escalate, no bold single recommendation there, oracle reveal clearly labeled, /about formulas/provenance, evaluation status. No default dashboard stock styling: restrained scorebook/workbench, prominent confidence gating.
- Prospective evaluation required, results pending accepted. Capture must precede outcome season (conservative Jan 1 cutoff, stricter than opening day); no clock override in production CLI. Cohort and baseline freeze before capture. Local append-only/hash-verified ledger cannot establish trusted external timestamp: state this limitation. Reject historical enrollment, overwrite/duplicates/tampering. Future scoring requires matching realized T+1 and source provenance; missing outcomes remain pending/excluded, not negative labels. Report Brier by role, baseline Brier, reliability buckets, coverage and missingness; never claim prospective success before outcomes. Historical plumbing tests explicitly non-prospective.
- Baseline probabilities must be frozen from development years only or declared fixed before predictions. No fitting on outcomes/holdout. Losses ship honestly; no accuracy guarantee. No Choice/Score calibration claim from Noul evaluation.
